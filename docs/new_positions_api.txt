================================================================================
                     新仓位检测 API 文档 (REST + WebSocket)
================================================================================

概述
----
新仓位检测系统实时监控 S 级交易员的仓位变化，当检测到新仓位时：
1. 保存到数据库 (detected_new_positions 表)
2. 通过 WebSocket 实时推送给订阅的客户端
3. 通过飞书发送通知

本文档包含 REST API 和 WebSocket 两部分。


================================================================================
                           REST API - 新仓位记录
================================================================================

Base URL: /api

响应格式:
  成功: { "success": true, "data": ..., "has_more": boolean, "next_before": number }
  失败: { "success": false, "error": "错误信息" }


--------------------------------------------------------------------------------
1. 获取新仓位记录（游标分页）
--------------------------------------------------------------------------------
GET /api/new-positions

描述: 获取检测到的新仓位记录，使用游标分页方式

查询参数:
  - before (integer, 可选): 游标ID，获取此ID之前的记录。为空则从最新记录开始
  - limit (integer, 可选): 返回数量限制，默认 50，最大 100
  - trader_address (string, 可选): 按交易员地址过滤
  - coin (string, 可选): 按币种过滤，如 BTC, ETH
  - direction (string, 可选): 按方向过滤，可选值: long, short
  - rating (string, 可选): 按交易员评级过滤，如 S, A, B
  - min_position_value (number, 可选): 最小仓位价值 (USD)
  - max_position_value (number, 可选): 最大仓位价值 (USD)
  - min_leverage (integer, 可选): 最小杠杆
  - max_leverage (integer, 可选): 最大杠杆

响应类型:
{
    success: boolean;
    data: NewPosition[];
    has_more: boolean;           // 是否还有更多数据
    next_before: number | null;  // 下一页的游标ID
}

使用示例:
  # 获取最新 20 条记录
  GET /api/new-positions?limit=20

  # 翻页：获取 ID < 1233 的下一批记录
  GET /api/new-positions?limit=20&before=1233

  # 筛选：仓位价值 >= $1000 且杠杆 >= 5x
  GET /api/new-positions?min_position_value=1000&min_leverage=5

  # 筛选：BTC 多单，仓位价值 $500-$5000
  GET /api/new-positions?coin=BTC&direction=long&min_position_value=500&max_position_value=5000

  # 筛选：S 级交易员，杠杆 10-20x
  GET /api/new-positions?rating=S&min_leverage=10&max_leverage=20

状态码:
  200 - 成功
  500 - 服务器错误


================================================================================
                           WebSocket API - 实时推送
================================================================================

连接信息
--------
WebSocket 端点: ws://{host}:{port}/socket.io
协议: Socket.IO (需使用 socket.io-client 库)

依赖:
  - 服务端需要 Redis 运行
  - 监控脚本 monitor_s_traders_positions.py 需要带 --redis 参数运行


--------------------------------------------------------------------------------
连接流程
--------------------------------------------------------------------------------

1. 客户端使用 socket.io-client 连接服务器
2. 连接成功后收到 'connected' 事件
3. 监听 'new_position' 事件接收新仓位通知


--------------------------------------------------------------------------------
事件列表
--------------------------------------------------------------------------------

[服务端 -> 客户端]

1. connected
   描述: 连接成功确认
   数据: { message: string }
   示例: { "message": "已连接到新仓位推送服务" }

2. new_position
   描述: 新仓位通知
   数据: NewPositionEvent
   
   interface NewPositionEvent {
       id: number;                  // 数据库记录ID
       trader_address: string;      // 交易员地址
       trader_name: string;         // 交易员名称
       trader_rating: string;       // 评级 (S/A/B/...)
       trader_score: number;        // 综合评分
       coin: string;                // 币种
       direction: "long" | "short"; // 方向
       szi: number;                 // 仓位大小
       entry_px: number;            // 开仓价格
       position_value: number;      // 仓位价值 (USD)
       leverage: number;            // 杠杆倍数
       detected_at: string;         // 检测时间 (ISO 8601)
       trade_url: string;           // 交易链接
   }
   
   示例:
   {
       "id": 1234,
       "trader_address": "0x1234567890abcdef1234567890abcdef12345678",
       "trader_name": "Top Trader",
       "trader_rating": "S",
       "trader_score": 85.5,
       "coin": "BTC",
       "direction": "long",
       "szi": 0.5,
       "entry_px": 42350.5,
       "position_value": 21175.25,
       "leverage": 10,
       "detected_at": "2024-01-15T10:30:00.000000",
       "trade_url": "https://app.hyperliquid.xyz/trade/BTC"
   }

3. pong
   描述: 心跳响应
   数据: { message: "pong" }

4. subscribed
   描述: 订阅确认
   数据: { channel: string }


[客户端 -> 服务端]

1. ping
   描述: 心跳检测
   数据: 无

2. subscribe
   描述: 订阅特定频道（预留扩展）
   数据: { channel: string }


--------------------------------------------------------------------------------
前端连接示例
--------------------------------------------------------------------------------

JavaScript (使用 socket.io-client):

```javascript
import { io } from 'socket.io-client';

// 连接 WebSocket
const socket = io('http://localhost:5000', {
    transports: ['websocket'],
    reconnection: true,
    reconnectionAttempts: 5,
    reconnectionDelay: 1000
});

// 连接成功
socket.on('connect', () => {
    console.log('WebSocket 已连接');
});

// 连接确认
socket.on('connected', (data) => {
    console.log('服务器确认:', data.message);
});

// 接收新仓位通知
socket.on('new_position', (data) => {
    console.log('新仓位:', data);
    
    // 示例：显示通知
    const direction = data.direction === 'long' ? '🟢 做多' : '🔴 做空';
    const message = `${data.trader_name} ${direction} ${data.coin} ` +
                   `$${data.position_value.toFixed(2)} ${data.leverage}x`;
    
    // 显示通知或更新 UI
    showNotification(message);
    
    // 可以跳转到交易页面
    // window.open(data.trade_url, '_blank');
});

// 断开连接
socket.on('disconnect', (reason) => {
    console.log('WebSocket 已断开:', reason);
});

// 连接错误
socket.on('connect_error', (error) => {
    console.error('连接错误:', error);
});

// 心跳检测
setInterval(() => {
    socket.emit('ping');
}, 30000);

socket.on('pong', () => {
    console.log('心跳正常');
});
```

React Hook 示例:

```typescript
import { useEffect, useState } from 'react';
import { io, Socket } from 'socket.io-client';

interface NewPosition {
    id: number;
    trader_address: string;
    trader_name: string;
    trader_rating: string;
    trader_score: number;
    coin: string;
    direction: 'long' | 'short';
    szi: number;
    entry_px: number;
    position_value: number;
    leverage: number;
    detected_at: string;
    trade_url: string;
}

export function useNewPositions(serverUrl: string) {
    const [positions, setPositions] = useState<NewPosition[]>([]);
    const [connected, setConnected] = useState(false);
    const [socket, setSocket] = useState<Socket | null>(null);

    useEffect(() => {
        const newSocket = io(serverUrl, {
            transports: ['websocket'],
            reconnection: true
        });

        newSocket.on('connect', () => {
            setConnected(true);
        });

        newSocket.on('disconnect', () => {
            setConnected(false);
        });

        newSocket.on('new_position', (data: NewPosition) => {
            setPositions(prev => [data, ...prev].slice(0, 100)); // 保留最新100条
        });

        setSocket(newSocket);

        return () => {
            newSocket.close();
        };
    }, [serverUrl]);

    return { positions, connected, socket };
}

// 使用示例
function NewPositionsComponent() {
    const { positions, connected } = useNewPositions('http://localhost:5000');

    return (
        <div>
            <div>状态: {connected ? '已连接' : '未连接'}</div>
            <ul>
                {positions.map(pos => (
                    <li key={pos.id}>
                        {pos.direction === 'long' ? '🟢' : '🔴'}
                        {pos.coin} ${pos.position_value.toFixed(2)}
                    </li>
                ))}
            </ul>
        </div>
    );
}
```
