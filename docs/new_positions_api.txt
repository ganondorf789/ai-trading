================================================================================
                     新仓位检测 API 文档 (REST + WebSocket)
================================================================================

概述
----
新仓位检测系统实时监控 S 级交易员的仓位变化，当检测到新仓位时：
1. 保存到数据库 (detected_new_positions 表)
2. 通过 WebSocket 实时推送给订阅的客户端
3. 通过飞书发送通知

本文档包含 REST API 和 WebSocket 两部分。


================================================================================
                           REST API - 新仓位记录
================================================================================

Base URL: /api

响应格式:
  成功: { "success": true, "data": ..., "has_more": boolean, "next_before": number }
  失败: { "success": false, "error": "错误信息" }


--------------------------------------------------------------------------------
1. 获取新仓位记录（游标分页）
--------------------------------------------------------------------------------
GET /api/new-positions

描述: 获取检测到的新仓位记录，使用游标分页方式

查询参数:
  - before (integer, 可选): 游标ID，获取此ID之前的记录。为空则从最新记录开始
  - limit (integer, 可选): 返回数量限制，默认 50，最大 100
  - trader_address (string, 可选): 按交易员地址过滤
  - coin (string, 可选): 按币种过滤，如 BTC, ETH
  - direction (string, 可选): 按方向过滤，可选值: long, short
  - rating (string, 可选): 按交易员评级过滤，如 S, A, B
  - min_position_value (number, 可选): 最小仓位价值 (USD)
  - max_position_value (number, 可选): 最大仓位价值 (USD)
  - min_leverage (integer, 可选): 最小杠杆
  - max_leverage (integer, 可选): 最大杠杆

响应类型:
{
    success: boolean;
    data: NewPosition[];
    has_more: boolean;           // 是否还有更多数据
    next_before: number | null;  // 下一页的游标ID
}

响应示例:
{
    "success": true,
    "data": [
        {
            "id": 1234,
            "trader_address": "0x1234...abcd",
            "trader_name": "Trader A",

            "direction": "long",

            "position_value": 21175.25,
            "leverage": 10,
            "detected_at": "2024-01-15T10:30:00+08:00",
            "notified": true,
            "created_at": "2024-01-15T10:30:00+08:00"
        },
        {
            "id": 1233,
            "trader_address": "0x5678...efgh",
            "trader_name": "Trader B",
            "trader_rating": "S",
            "trader_score": 82.3,
            "coin": "ETH",
            "direction": "short",
            "szi": 5.0,
            "entry_px": 2250.0,

    "has_more": true,
    "next_before": 1233

使用示例:
  # 获取最新 20 条记录
  GET /api/new-positions?limit=20

  # 翻页：获取 ID < 1233 的下一批记录
  GET /api/new-positions?limit=20&before=1233

  # 筛选：仓位价值 >= $1000 且杠杆 >= 5x
  GET /api/new-positions?min_position_value=1000&min_leverage=5

  # 筛选：BTC 多单，仓位价值 $500-$5000
  GET /api/new-positions?coin=BTC&direction=long&min_position_value=500&max_position_value=5000

  # 筛选：S 级交易员，杠杆 10-20x
  GET /api/new-positions?rating=S&min_leverage=10&max_leverage=20

状态码:
  200 - 成功
  500 - 服务器错误


================================================================================
                           WebSocket API - 实时推送
================================================================================

连接信息
--------
WebSocket 端点: ws://{host}:{port}/socket.io
协议: Socket.IO (需使用 socket.io-client 库)

依赖:
  - 服务端需要 Redis 运行
  - 监控脚本 monitor_s_traders_positions.py 需要带 --redis 参数运行


--------------------------------------------------------------------------------
连接流程
--------------------------------------------------------------------------------

1. 客户端使用 socket.io-client 连接服务器
2. 连接成功后收到 'connected' 事件
3. 监听 'new_position' 事件接收新仓位通知


--------------------------------------------------------------------------------
事件列表
--------------------------------------------------------------------------------

[服务端 -> 客户端]

1. connected
   描述: 连接成功确认
   数据: { message: string }
   示例: { "message": "已连接到新仓位推送服务" }

2. new_position
   描述: 新仓位通知
   数据: NewPositionEvent
   
   interface NewPositionEvent {
       id: number;                  // 数据库记录ID
       trader_address: string;      // 交易员地址
       trader_name: string;         // 交易员名称
       trader_rating: string;       // 评级 (S/A/B/...)
       trader_score: number;        // 综合评分
       coin: string;                // 币种
       direction: "long" | "short"; // 方向
       szi: number;                 // 仓位大小
       entry_px: number;            // 开仓价格
       position_value: number;      // 仓位价值 (USD)
       leverage: number;            // 杠杆倍数
       detected_at: string;         // 检测时间 (ISO 8601)
       trade_url: string;           // 交易链接
   }
   
   示例:
   {
       "id": 1234,
       "trader_address": "0x1234567890abcdef1234567890abcdef12345678",
       "trader_name": "Top Trader",
       "trader_rating": "S",
       "trader_score": 85.5,
       "coin": "BTC",
       "direction": "long",
       "szi": 0.5,
       "entry_px": 42350.5,
       "position_value": 21175.25,
       "leverage": 10,
       "detected_at": "2024-01-15T10:30:00.000000",
       "trade_url": "https://app.hyperliquid.xyz/trade/BTC"
   }

3. pong
   描述: 心跳响应
   数据: { message: "pong" }

4. subscribed
   描述: 订阅确认
   数据: { channel: string }


[客户端 -> 服务端]

1. ping
   描述: 心跳检测
   数据: 无

2. subscribe
   描述: 订阅特定频道（预留扩展）
   数据: { channel: string }


--------------------------------------------------------------------------------
前端连接示例
--------------------------------------------------------------------------------

JavaScript (使用 socket.io-client):

```javascript
import { io } from 'socket.io-client';

// 连接 WebSocket
const socket = io('http://localhost:5000', {
    transports: ['websocket'],
    reconnection: true,
    reconnectionAttempts: 5,
    reconnectionDelay: 1000
});

// 连接成功
socket.on('connect', () => {
    console.log('WebSocket 已连接');
});

// 连接确认
socket.on('connected', (data) => {
    console.log('服务器确认:', data.message);
});

// 接收新仓位通知
socket.on('new_position', (data) => {
    console.log('新仓位:', data);
    
    // 示例：显示通知
    const direction = data.direction === 'long' ? '🟢 做多' : '🔴 做空';
    const message = `${data.trader_name} ${direction} ${data.coin} ` +
                   `$${data.position_value.toFixed(2)} ${data.leverage}x`;
    
    // 显示通知或更新 UI
    showNotification(message);
    
    // 可以跳转到交易页面
    // window.open(data.trade_url, '_blank');
});

// 断开连接
socket.on('disconnect', (reason) => {
    console.log('WebSocket 已断开:', reason);
});

// 连接错误
socket.on('connect_error', (error) => {
    console.error('连接错误:', error);
});

// 心跳检测
setInterval(() => {
    socket.emit('ping');
}, 30000);

socket.on('pong', () => {
    console.log('心跳正常');
});
```

React Hook 示例:

```typescript
import { useEffect, useState } from 'react';
import { io, Socket } from 'socket.io-client';

interface NewPosition {
    id: number;
    trader_address: string;
    trader_name: string;
    trader_rating: string;
    trader_score: number;
    coin: string;
    direction: 'long' | 'short';
    szi: number;
    entry_px: number;
    position_value: number;
    leverage: number;
    detected_at: string;
    trade_url: string;
}

export function useNewPositions(serverUrl: string) {
    const [positions, setPositions] = useState<NewPosition[]>([]);
    const [connected, setConnected] = useState(false);
    const [socket, setSocket] = useState<Socket | null>(null);

    useEffect(() => {
        const newSocket = io(serverUrl, {
            transports: ['websocket'],
            reconnection: true
        });

        newSocket.on('connect', () => {
            setConnected(true);
        });

        newSocket.on('disconnect', () => {
            setConnected(false);
        });

        newSocket.on('new_position', (data: NewPosition) => {
            setPositions(prev => [data, ...prev].slice(0, 100)); // 保留最新100条
        });

        setSocket(newSocket);

        return () => {
            newSocket.close();
        };
    }, [serverUrl]);

    return { positions, connected, socket };
}

// 使用示例
function NewPositionsComponent() {
    const { positions, connected } = useNewPositions('http://localhost:5000');

    return (
        <div>
            <div>状态: {connected ? '已连接' : '未连接'}</div>
            <ul>
                {positions.map(pos => (
                    <li key={pos.id}>
                        {pos.direction === 'long' ? '🟢' : '🔴'}
                        {pos.coin} ${pos.position_value.toFixed(2)}
                    </li>
                ))}
            </ul>
        </div>
    );
}
```


================================================================================
                     跟单通知 API (REST + WebSocket)
================================================================================

概述
----
跟单通知系统用于实时推送跟单交易的状态变化，包括：
- 开仓通知 (open)
- 平仓通知 (close)
- 调仓通知 (adjust)
- 错误通知 (error)

通知内容支持 Markdown 格式，便于前端渲染。


--------------------------------------------------------------------------------
REST API - 获取通知记录（游标分页）
--------------------------------------------------------------------------------
GET /api/notifications

描述: 获取跟单通知记录，使用游标分页方式

查询参数:
  - before (integer, 可选): 游标ID，获取此ID之前的记录。为空则从最新记录开始
  - after (integer, 可选): 游标ID，获取此ID之后的记录（用于获取更新的数据）
  - limit (integer, 可选): 返回数量限制，默认 50，最大 100
  - type (string, 可选): 按通知类型过滤，可选值: open, close, adjust, error
  - is_read (boolean, 可选): 按已读状态过滤
  - symbol (string, 可选): 按交易对过滤，如 BTC, ETH
  - target_address (string, 可选): 按目标交易员地址过滤

响应类型:
{
    success: boolean;
    data: Notification[];
    pagination: {
        has_more: boolean;       // 是否还有更多数据
        next_cursor: number | null;  // 下一页的游标ID
    }
}

响应示例:

            "id": 99,
            "type": "close",
            "title": "💰 平仓",
            "content": "**目标**: 0x1234567890...\n**交易对**: ETH\n**盈亏**: +$150.00",
            "target_address": "0x1234567890abcdef1234567890abcdef12345678",
            "symbol": "ETH",
            "side": null,
            "size": null,
            "pnl": 150.0,

使用示例:
  # 获取最新 20 条通知
  GET /api/notifications?limit=20

  # 翻页：获取 ID < 99 的下一批记录
  GET /api/notifications?limit=20&before=99

  # 获取新通知（轮询）：获取 ID > 100 的记录
  GET /api/notifications?after=100

  # 筛选：仅开仓通知
  GET /api/notifications?type=open

  # 筛选：未读的 BTC 相关通知
  GET /api/notifications?is_read=false&symbol=BTC

状态码:
  200 - 成功
  500 - 服务器错误

    }

React Hook 示例:

```typescript
import { useEffect, useState } from 'react';
import { io, Socket } from 'socket.io-client';

interface Notification {
    id: number;
    type: 'open' | 'close' | 'adjust' | 'error';
    title: string;
    content: string;
    target_address: string | null;
    symbol: string | null;
    side: 'long' | 'short' | null;
    size: number | null;
    pnl: number | null;
    timestamp: string;
}

export function useNotifications(serverUrl: string) {
    const [notifications, setNotifications] = useState<Notification[]>([]);
    const [unreadCount, setUnreadCount] = useState(0);

    useEffect(() => {
        const socket = io(serverUrl, {
            transports: ['websocket'],
            reconnection: true
        });

        socket.on('notification', (data: Notification) => {
            setNotifications(prev => [data, ...prev].slice(0, 50));
            setUnreadCount(prev => prev + 1);
        });

        return () => {
            socket.close();
        };
    }, [serverUrl]);

    const markAllRead = () => setUnreadCount(0);

    return { notifications, unreadCount, markAllRead };
}

// 使用示例
function NotificationBell() {
    const { notifications, unreadCount, markAllRead } = useNotifications('http://localhost:5000');
    const [showList, setShowList] = useState(false);

    return (
        <div>
            <button onClick={() => { setShowList(!showList); markAllRead(); }}>
                🔔 {unreadCount > 0 && <span className="badge">{unreadCount}</span>}
            </button>
            {showList && (
                <ul className="notification-list">
                    {notifications.map(n => (
                        <li key={n.id} className={`notification-${n.type}`}>
                            <div className="title">{n.title}</div>
                            <div className="content" dangerouslySetInnerHTML={{ 
                                __html: marked(n.content) 
                            }} />
                            <div className="time">{n.timestamp}</div>
                        </li>
                    ))}
                </ul>
            )}
        </div>
    );
}
```

================================================================================
                           补仓 API (REST)
================================================================================

概述
----
补仓 API 用于在现有仓位基础上增加持仓量。系统会自动检测当前仓位方向，
并以相同方向下单。支持市价补仓和限价补仓两种方式。


--------------------------------------------------------------------------------
1. 市价补仓
--------------------------------------------------------------------------------
POST /api/trading/positions/{symbol}/add

描述: 以市价对指定交易对的现有仓位进行补仓

路径参数:
  - symbol (string, 必填): 交易对符号，如 BTC, ETH

请求体:
{
    "size": number,           // 补仓数量（与 amount 二选一）
    "amount": number,         // 补仓金额 USDC（与 size 二选一，按当前价格计算数量）
    "slippage": number,       // 滑点容忍度，默认 0.01 (1%)
    "leverage": number,       // 杠杆倍数（可选，不提供则使用当前杠杆）
    "is_cross": boolean       // 是否全仓模式，默认 true（仅在设置杠杆时生效）
}

请求示例:
  # 按数量补仓 0.1 BTC
  POST /api/trading/positions/BTC/add
  { "size": 0.1 }

  # 按金额补仓 $500 USDC
  POST /api/trading/positions/BTC/add
  { "amount": 500 }

  # 补仓并调整杠杆到 20x
  POST /api/trading/positions/ETH/add
  { "size": 1.0, "leverage": 20 }

  # 补仓 $1000，滑点 0.5%
  POST /api/trading/positions/BTC/add
  { "amount": 1000, "slippage": 0.005 }

响应类型:
{
    success: boolean;
    data: object;              // 订单执行结果
    position: {                // 补仓前的仓位信息
        symbol: string;
        side: 'long' | 'short';
        size_before: number;
        entry_price: number;
        leverage_before: number;
    };
    added_size: number;        // 实际补仓数量
    leverage?: number;         // 设置的新杠杆（如果有）
    leverage_result?: object;  // 杠杆设置结果（如果有）
    message: string;
}

响应示例:
{
    "success": true,
    "data": {
        "statuses": [
            {
                "resting": {
                    "oid": 123456789
                }
            }
        ]
    },
    "position": {
        "symbol": "BTC",
        "side": "long",
        "size_before": 0.5,
        "entry_price": 42000.0,
        "leverage_before": 10
    },
    "added_size": 0.1,
    "message": "BTC 市价补仓成功，补仓数量: 0.1"
}

状态码:
  200 - 补仓成功
  400 - 参数错误（size/amount 必须提供一个且仅一个，数量必须大于0）
  404 - 仓位不存在
  500 - 服务器错误


--------------------------------------------------------------------------------
2. 限价补仓
--------------------------------------------------------------------------------
POST /api/trading/positions/{symbol}/add-limit

描述: 以限价对指定交易对的现有仓位进行补仓（挂单）

路径参数:
  - symbol (string, 必填): 交易对符号，如 BTC, ETH

请求体:
{
    "price": number,          // 限价（必填）
    "size": number,           // 补仓数量（与 amount 二选一）
    "amount": number,         // 补仓金额 USDC（与 size 二选一，按 price 计算数量）
    "post_only": boolean,     // 是否只做 maker，默认 false
    "leverage": number,       // 杠杆倍数（可选，不提供则使用当前杠杆）
    "is_cross": boolean       // 是否全仓模式，默认 true（仅在设置杠杆时生效）
}

请求示例:
  # 以 $41000 限价补仓 0.2 BTC
  POST /api/trading/positions/BTC/add-limit
  { "price": 41000, "size": 0.2 }

  # 以 $2200 限价补仓 $1000 USDC 的 ETH（约 0.45 ETH）
  POST /api/trading/positions/ETH/add-limit
  { "price": 2200, "amount": 1000 }

  # 限价补仓，只做 maker，杠杆 15x
  POST /api/trading/positions/BTC/add-limit
  { "price": 40000, "size": 0.5, "post_only": true, "leverage": 15 }

响应类型:
{
    success: boolean;
    data: object;              // 订单执行结果
    position: {                // 补仓前的仓位信息
        symbol: string;
        side: 'long' | 'short';
        size_before: number;
        entry_price: number;
        leverage_before: number;
    };
    added_size: number;        // 补仓数量
    price: number;             // 限价
    leverage?: number;         // 设置的新杠杆（如果有）
    leverage_result?: object;  // 杠杆设置结果（如果有）
    message: string;
}

状态码:
  200 - 订单提交成功
  400 - 参数错误（缺少 price，size/amount 必须提供一个且仅一个）
  404 - 仓位不存在
  500 - 服务器错误


--------------------------------------------------------------------------------
补仓逻辑说明
--------------------------------------------------------------------------------

1. 方向自动判断:
   - 系统自动获取当前仓位方向
   - 多仓 (long) 补仓 → 买入
   - 空仓 (short) 补仓 → 卖出

2. 数量计算:
   - 提供 size: 直接使用该数量
   - 提供 amount: 
     - 市价补仓: amount / 当前市场价格
     - 限价补仓: amount / 限价

3. 杠杆设置:
   - 如果提供 leverage 参数，会在下单前先设置杠杆
   - 不提供则保持当前杠杆不变
   - 杠杆设置会影响该交易对的后续所有订单

4. 前置检查:
   - 必须已有该交易对的仓位才能补仓
   - 如果没有仓位，返回 404 错误
